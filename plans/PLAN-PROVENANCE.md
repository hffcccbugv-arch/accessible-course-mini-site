# Plan provenance

The plan files in the supplied ZIP carry the same timestamp as the page files (2026-11-24 17:29), so it cannot be proven from the files that the plans were written before the markup. No earlier dates are claimed.

This revision rewrote the plans from the built pages and from the test results, so they describe what the site does now. They are documentation of the build, not proof of a plan-first workflow. If the course needs plan-first proof, the student would have to supply their own earlier drafts or version history.
