# Accessible Course Mini-Site (edited copy)

**Original work:** the site's design, text and structure were created by Yousef (GitHub Pages project "project-1"). This repository is an **edited copy** published by Mazen Rashad for study purposes. It is not original work by Mazen.

**What was edited:** a set of accessibility and markup fixes made in this copy by an AI assistant at Mazen's request. Every change is listed in [CHANGES.md](CHANGES.md). The original repository was not modified.

**Testing status:** the test results in `evidence/test-cases.md` were run by an AI assistant in headless Chrome, on a local copy. A second browser, a screen reader and the student reflection are not done. See `README.txt` for the full notes.

**Form note:** the registration form posts to a local `node server.js` endpoint (see `README.txt`). On this static GitHub Pages site the form cannot submit. It is a front-end demonstration only.
