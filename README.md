# Accessible Course Mini-Site (edited copy)

**Original work:** the site's design, text and structure were created by Yousef (GitHub Pages project "project-1"). This repository is an **edited copy** published by Mazen Rashad for study purposes. It is not original work by Mazen. The original repository was not modified.

**What was edited:** accessibility and markup fixes, tests, plans, evidence and a reflection draft, prepared with an AI assistant at Mazen's request (AI use is disclosed here as the course requires). Every change is listed in [CHANGES.md](CHANGES.md). Requirement-by-requirement status is in [STATUS.md](STATUS.md).

**Testing status:** 34 test cases were run by script in Chrome 157 and Firefox 161 (headless) on a local copy; results are in `evidence/test-cases.md`. The HTML validator reports 0 messages on all four pages. **No screen reader was run.** The reflection is a draft that the student must review and confirm.

**Form note:** the registration form posts to a local `node server.js` endpoint (see `README.txt`). On this static GitHub Pages site the form cannot submit. It is a front-end demonstration only.
