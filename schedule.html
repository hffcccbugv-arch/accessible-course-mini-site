How to read the timetable

Take the cell “Lecture — Dr. Hend Shaaban”. Three headers describe it: the row header “Sunday”, the column header “Instructor / session”, and the column group “Session details” above it. A screen reader announces those headers as you move into the cell, so the cell reads as: Sunday, Session details, Instructor / session, Lecture, Dr. Hend Shaaban. The “Day” header spans two header rows because it covers both the group row and the column-header row.
